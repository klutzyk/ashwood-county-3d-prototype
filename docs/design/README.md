# Ashwood County World Guide

> *"A believable county before it became a zombie apocalypse."*

---

## Purpose

The **Ashwood County World Guide** is the authoritative reference for the game's world.

Unlike the development roadmap, which describes *how the game will be built*, this guide describes *what the world is*.

Every town, road, landmark, building, biome, and story should have a logical place within Ashwood County before it is implemented in Godot.

This document is intended to ensure that every addition to the game contributes to a cohesive, believable world.

---

# Design Philosophy

Ashwood County is not designed as a collection of game levels.

It is designed as a real county that existed long before the outbreak.

Every location should answer five questions:

1. Why was it built?
2. What happened there during the outbreak?
3. Why would the player visit?
4. Why is it dangerous?
5. What makes it memorable?

If a location cannot answer all five questions, it should be redesigned.

---

# World Design Principles

## Believable over gigantic

The world should feel authentic rather than oversized.

A smaller, carefully designed county is preferable to a massive empty landscape.

---

## Every location tells a story

Buildings are not simply containers for loot.

They represent lives interrupted by the outbreak.

---

## Exploration should always reward curiosity

Interesting discoveries should exist away from the main roads.

Players should feel rewarded for investigating unusual places.

---

## Gameplay emerges from the world

Gameplay should naturally arise from believable locations.

Hospitals contain medicine because they are hospitals.

Garages contain tools because mechanics worked there.

Nothing exists solely because "the game needs it."

---

## Consistency above realism

Absolute realism is not the objective.

Consistency is.

The county should follow its own internal logic.
