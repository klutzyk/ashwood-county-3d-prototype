# Miller Hardware Fixture Sources

The fixture geometry in this directory was authored for Ashwood County and is
generated by `tools/build_miller_hardware_fixtures.py`. Blender consolidates
each fixture by material, and Godot extracts the embedded texture maps beside
the imported GLBs for reliable Compatibility-renderer imports.
